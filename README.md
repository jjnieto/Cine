# Productoras

Plataforma para que una asociación de productoras de cine financie películas mediante la emisión de bonos tokenizados, gobernada por las productoras y abierta a inversores (cinéfilos) bajo KYC.

Construida sobre Hyperledger Fabric.

Ver [CLAUDE.md](./CLAUDE.md) para arquitectura, comandos y decisiones de diseño.
